# Java Port Scanner

A simple TCP Port Scanner built using Java.

## Features

- Scan a hostname or IP address
- Scan a range of ports
- Detect open TCP ports
- Simple command-line interface
- Configurable connection timeout

## Technologies

- Java
- Java Sockets
- VS Code
